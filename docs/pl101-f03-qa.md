## UX-beslutninger
Lær får ett kompakt F03-kort øverst, med 0/5 og 0 % før data finnes. CTA bruker
alltid første uavhukede steg i fast rekkefølge, uavhengig av sist besøkt. Sist
åpnet vises separat. 5/5 gir Repeter til første steg. Alle steg kan åpnes fritt.
Aktuelt steg har aria-current=step; egen gjennomgang har separat status.

Avhuking betyr egen gjennomgang av steget/oversikten, aldri fullført aktivitet,
mestring eller faglig godkjenning. Dette står eksplisitt i grensesnittet, også
når selve aktiviteten mangler. Reset krever bekreftelse og berører bare F03.

## Datamodell/personvern
learning-journey-model.js er gjenbrukbar logikk, bare F03 er aktivert.
Nøkkel: modus.learning-journey.F03.v1. JSON: version=1, module=F03,
checked=[stabile steg-ID-er], lastVisited=null/step-ID. Ingen tidsstempler,
brukeridentifikatorer, tracking, konto, server eller endring i atlasnøkler.

Ugyldig JSON, ukjent modul/versjon/step-data gir tom tilstand og forklaring.
Versjon 0 med completed-array migreres til v1 uten ny kompetansestatus.
Blokkert lesing/skriving gir fungerende minnebasert UI på siden med eksplisitt
varsel om tap ved navigasjon/reload. Data er per nettleser/enhet og synkroniseres
ikke. Slettet lagring og storage-event/reset oppdaterer kortet; pageshow oppdaterer
ved tilbakeknapp/BFCache. Inkompatibel post overskrives først ved ny interaksjon
(også åpning av et steg); ingen andre nøkler slettes.

## Automatiske tester / skjermbilder
npm run build; npm test (25 kontrolloppføringer). Nye modelltester dekker
0–5, angre/neste, runde gjennom JSON, malformed/schema/module og v0-migrering.
Learning-journey-browser kjører i eksisterende pianonettlesersteg, med egne
resultatfiler journey-*-results.json og pl101-*.png i CI-artefakten.
Chromium/WebKit × NO/EN × 1440/375: første besøk, 5/5/Repeter, angre,
reload/sist besøkt, tastatur/fokus, reset uten atlasendring, ugyldig lagring,
blokkert lagring og reduced-motion. 200 % testes med CSS zoom=2; dette er ikke
manuell nettleserzoom eller full skjermlesertest. Skjermbilder tas før CSS-zoom.
